# INTERVUE — Scoring System

## Overview

The INTERVUE scoring system uses a **hybrid model**:

- **LLM Evaluation**: The AI Evaluator (`ai/answer-evaluator.ts`) produces raw dimension scores (0–10) for each answer based on semantic analysis of the candidate's response.
- **Deterministic Calculation**: The application code (`lib/scoring.ts`) applies a fixed weighted formula to those LLM-generated scores to produce the final composite score.

The final weighted score is **never generated by the LLM**. This ensures reproducibility and eliminates hallucination risk in the final numeric output.

---

## Scoring Formula

Each answer is evaluated across 5 dimensions. Individual scores are on a **0–10 scale**.
The final composite score is on a **0–100 scale**.

| Dimension | Weight | Description |
|-----------|--------|-------------|
| **Technical Correctness** | **35%** | Is the answer factually accurate? Does it correctly apply the relevant concept? |
| **Reasoning** | **25%** | Does the candidate reason logically? Do they explain the *why* behind their answer? |
| **Depth** | **20%** | Does the answer go beyond surface-level recall to demonstrate genuine understanding? |
| **Communication** | **10%** | Is the answer clear, structured, and articulate? |
| **Practical Engineering** | **10%** | Does the candidate demonstrate real-world applicability and engineering judgement? |
| **TOTAL** | **100%** | |

### Formula

```
compositeScore = (
  correctness × 0.35 +
  reasoning   × 0.25 +
  depth       × 0.20 +
  communication × 0.10 +
  engineering × 0.10
) × 10
```

The `× 10` conversion maps the weighted sum (0–10 scale) to the 0–100 scale.

---

## Session Score

The final **Interview DNA** overall score is the arithmetic mean of all individual
turn composite scores across the session:

```
sessionScore = mean(compositeScore_1, compositeScore_2, ..., compositeScore_n)
```

Implemented in `lib/scoring.ts` → `calculateSessionScore()`.

---

## Confidence Levels

The Knowledge Twin uses confidence levels to indicate how reliable each topic estimate is:

| Confidence | Evidence Count | Meaning |
|------------|----------------|---------|
| `low` | 1–2 | Early estimate; could change significantly |
| `medium` | 3–4 | Reasonably reliable estimate |
| `high` | 5+ | High confidence in the estimated topic score |

## Implementation

See [`lib/scoring.ts`](../lib/scoring.ts) for the full implementation.

The scoring module exports:
- `calculateScore(evaluation)` → `ScoringResult`
- `calculateSessionScore(evaluations[])` → `number`
- `getScoringWeights()` → weight configuration
